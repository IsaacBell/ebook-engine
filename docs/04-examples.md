# Examples

These books in the GridLab repo were built with Ebook Engine.

## IT Guide

`content/it-guide/` — HTML intake from exported chapters. Built as both PDF and a themed HTML demo deployed to Vercel.

```bash
just build-ebook-from-config content/it-guide/
```

## grid[lab] Guidebook

`content/guidebook/` — long-form markdown on digital security and privacy.

```bash
just build-ebook-from-config content/guidebook/
```

## Jujutsu for Busy Developers

`writing/guides/jujutsu-for-busy-developers/` — a technical guide built from markdown and notebook sources.

## This documentation

`apps/ebook-engine/docs/` — the documentation you are reading is itself an Ebook Engine book built to HTML and deployed to GitHub Pages.
